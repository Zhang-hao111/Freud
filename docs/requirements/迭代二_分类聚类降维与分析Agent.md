# 迭代二：分类、聚类、降维与分析 Agent

## 1. 目标与最终效果

本轮使用 MovieLens 1M 清洗数据，在第一轮数据治理 Agent 的基础上增加三类分析能力，用于回答以下问题：

1. **分类：** 对一个用户与电影的组合，预测该用户在发生评分时是否会给出不低于 4 分的评分。
2. **聚类：** 根据用户的历史观影偏好，将用户划分为若干具有可解释性的群体。
3. **降维：** 将用户偏好画像压缩到较低维度，展示主要变化方向，并比较压缩前后聚类质量、信息保留情况和资源开销。

前置输入包括第一轮输出的清洗数据、数据版本、评估报告和时间边界 `T1/T2`。前置数据缺失或版本不一致时，系统应返回明确的状态说明，不得基于缺失数据生成分析结果。

模型训练和用户画像构建只能使用训练期数据。验证期数据用于算法选择与参数调整，测试期数据只能在方案确定后用于最终评价。对评分事件构造分类特征时，不得使用该事件发生后的信息。

分类、聚类和降维三类任务均须从相应 PPT 介绍的算法中任选两种进行实现，并将每种算法封装为可供 Agent 独立调用的工具。特征、参数和评价口径可结合数据特点自行设计，但必须记录算法选型依据、实际配置和运行结果。

本轮应保留分类模型、用户画像、用户群体、降维模型及坐标、算法参数、评价指标和版本信息，供第三轮构建知识图谱和执行后续任务时使用。

Agent 只能返回已登记的实际结果。模型、数据或评价结果不可用时，应返回“未完成”或“数据不可用”等明确状态，不得使用示例数据或推测结果替代。

## 2. 分类分析需求

- **Agent 输入：** 用户的自然语言问题、目标 `UserID` 和目标 `MovieID`。用户可指定一种已实现的分类算法；未指定时，Agent 调用两种分类算法进行对照。
- **Agent 输出：** 返回实际调用算法的名称、预测类别、正类概率或决策分数、模型版本、算法参数和评价指标。遇到未知 ID、模型缺失或无法预测等情况时，应返回明确的状态说明，不得生成占位结果。

## 3. 聚类分析需求

- **Agent 输入：** 用户的自然语言问题，以及目标 `UserID` 或待分析的用户集合。用户可指定一种已实现的聚类算法及其参数；未指定时，Agent 调用两种聚类算法进行对照。
- **Agent 输出：** 返回实际调用算法的名称、用户群体归属、群体摘要、模型或结果版本、实际参数和评价指标。若算法支持噪声点识别，还应返回噪声点标记。遇到用户历史不足、用户不存在或结果尚未生成等情况时，应返回明确的状态说明。

## 4. 降维与聚类对照需求

- **Agent 输入：** 用户的自然语言问题和待分析的用户集合。用户可指定一种已实现的降维算法、目标维数或信息保留阈值，以及用于对照的聚类算法及其参数；未指定降维算法时，Agent 调用两种降维算法进行对照。
- **Agent 输出：** 返回实际调用算法的名称、降维坐标、原始维数、实际降维维数、模型或结果版本、信息保留情况、算法参数和资源开销，并提供原始用户画像与降维表示上的聚类结果对照及二维可视化。遇到输入无效或结果尚未生成等情况时，应返回明确的状态说明。

## 5. 前端展示需求

系统应提供简易前端页面，允许用户输入问题、了解任务状态并查看三类分析结果。页面应满足以下要求：

| 功能 | 需求说明 |
| --- | --- |
| 问题输入 | 用户可以输入自然语言问题并发起查询。 |
| 执行情况 | 展示任务状态和当前进展，失败时说明失败环节和原因。 |
| 分类结果 | 展示目标用户与电影、预测高分概率或类别、使用的模型版本、评价指标和适用限制。 |
| 聚类结果 | 展示用户群体归属、群体摘要、代表性内容、历史不足提示和群体解释。 |
| 降维结果 | 展示信息保留情况、二维图、压缩前后对照及资源开销。 |
| 实验对照 | 展示两种算法的评价指标、数据切分方式、版本信息和实际差异。 |
| 证据与追问 | 展示结果依据、未验证内容和局限，并允许用户继续追问。 |
| 结果获取 | 用户可以查看画像、预测和群体结果样例，并获取评价报告和必要图表。 |

页面内容必须与实际分析结果保持一致，明确区分预测、统计描述、可验证结论和推测。未知 ID、历史不足、未完成评估和不适用指标都应清晰标注。页面布局、展示形式和技术选型由学生自主决定，不要求复杂设计。
